#2

Reimbursement Form & IAM Basics

2026-07-06

Do This First

  • Before submitting the form, complete ≥5 skill badges
  • 1 is mandatory: "Create your first Gemini Enterprise App"
  • Badges must be "completed," not "started" — submitting early does not get you the voucher sooner

Form Field Notes

  • Name + registration (work) email
  • Personal email — pick one you actually check
  • Cohort ID: ASO3
  • Certification: choose Associate Cloud Engineer — don't pick PCA/PDE by mistake

Google Skills Profile

  • Settings → change visibility to Public
  • Must click Save, otherwise the link never generates
  • Paste the public link into the form

IAM in One Line

  • Who (user/group) + can do what (role) + on which resource
  • Predefined (Google-made) → try this first
  • Custom → assemble your own permission bundle
  • Basic (Owner/Editor/Viewer) → coarsest scope, last resort

Resource Hierarchy

  • Organization → Folder → Project → Resource
  • Permissions granted higher up flow down: 150 projects needing the same permission? Set it once at the org level
  • Project ID is locked after creation; the display name can still be changed later

Compute Engine Machine Types

  • Pick a family by workload: compute / memory / network optimized
  • Bandwidth scales with vCPU count, capped at 32 Gbps — need more? Turn on Tier 1 networking (100 Gbps, extra cost)
  • Every VM needs at least 1 internal IP
Global / Regional / Zonal cheat sheet

Global: VPC, some Load Balancers. Regional: GCS bucket, subnet, GKE cluster (the highest scope it gets), MIG. Zonal: the VM instance itself, Persistent Disk (mostly), Cloud SQL (by default). A VM is always zonal — this is the most commonly tested trap.

#3

The Storage Map: GCS & Cloud SQL

2026-07-13

Storage Classes

  • Standard→Nearline→Coldline→Archive — the less it's accessed, the cheaper
  • Lifecycle Policy: auto move/delete based on conditions
  • Autoclass: auto switches class based on actual access patterns (rare in practice)

The Three Encryption Keys

  • GMEK: Google-managed, default, nothing to manage
  • CMEK: your key, stored at Google
  • CSEK: your key, you hold it yourself (lose it = data gone)

Lock It Down

  • Retention Policy: bucket-level lock on a minimum age; once locked, can't be deleted
  • Object Hold: object-level version of the same idea
  • New rule: versioning can now be used together with a retention policy (older materials may say otherwise)
  • Uniform bucket-level access: IAM only, ACLs turned off

Cloud SQL High Availability

  • Default is single zone (zonal)
  • Enable HA = automatic cross-zone failover
  • Read Replica = failover requires a manual switch — don't mix these up!
  • Deleting/stopping an instance does not auto-backup — only 4 days of backups are kept
Migration cheat sheet

Moving external data into GCS? Storage Transfer Service covers 90–95% of cases. Migrating heterogeneous databases (e.g. Oracle → Cloud SQL) uses DMS.

#4

GKE Adventures & Compute Choices

2026-07-20

Autopilot vs Standard

  • Autopilot: fully managed, always regional, slightly pricier
  • Standard: you manage it, can be zonal or regional, cheaper
  • Small pilot project that doesn't need HA → pick zonal Standard

Getting a Private Cluster Online

  • Nodes with no external IP = Private Cluster
  • To reach Google services → Private Google Access
  • To reach the outside internet → Cloud NAT
  • Workload Identity: K8s SA borrows a GCP SA directly — no key file needed

Pick One: How to Run a Web App

  • Cloud Functions: purely event-driven, not meant for serving sites
  • App Engine: Standard can scale to zero / Flexible keeps at least one instance running
  • Cloud Run: requires stateless; when both options work, pick this first

Terraform Mnemonic

  • Four files: cloudbuild config / backend.tf / tfstate / main.tf
  • Four commands: init → plan → apply → destroy
Compliance Trap

Google holding PCI-DSS / GDPR / HIPAA certifications does not automatically make what you build on top compliant — it's shared responsibility. Exam questions about "how do I force data to stay in a specific region" → the answer is Organization Policy, not a compliance question.

#5

BigQuery & the Data Warehouse Family

2026-07-27

Three Similar-Sounding Names

  • Filestore: NFS file sharing, not a database
  • Firestore: NoSQL document database
  • Firebase: an app development platform, not a database

Three Ways to Save Money on BigQuery

  • Query cache: identical queries re-run free within 24 hours
  • Table Expiration: data auto-deletes on expiry, no manual tracking needed
  • Partitioning + Clustering: only scan the slice of data you actually need

Cloud Spanner's Superpower

  • The only relational database that scales horizontally (add nodes to go faster)
  • Cost: DB logic (triggers/stored procedures) has to move to the application layer
  • Cost: locks you into GCP, hard to switch cloud providers

Who Bigtable Is For

  • Key-value, wide-column, the first choice for time-series data
  • Need "read-heavy + ultra-low latency" analytics? It can also substitute for BigQuery
Command Mnemonic

Every gcloud command follows gcloud [group] [subgroup] [action], e.g. gcloud compute snapshots list. Snapshots have no get action — only list / describe / delete.

#6

HA, DR & Pre-Exam Prep

2026-08-03 (Final Session)

HA = Automatic Response

  • Compute Engine → Regional MIG + LB
  • GKE → Regional Cluster + LB
  • App Engine / Spanner / GCS → already highly available, no setup needed
  • Cloud SQL → check Multi-zone

DR = Requires a Human Decision

  • Cold: restore from backup, slow but simple
  • Warm: cross-region Read Replica, faster but manual failover
  • Hot: Cloud SQL has no native option — must switch to Cloud Spanner
  • DR is never fully automatic — the biggest difference from HA

Don't Mix Up Identities

  • Service Account: machine-to-machine
  • Cloud Identity: manages "human" accounts (e.g. imported from AD)
  • PII data → fine-grained permissions beat "a share link with an expiry date"

Exam Registration Cheat Sheet

  • About 50 questions / 2 hours
  • Test center version: just bring ID
  • Remote/home version: personal laptop + webcam/mic, room scan required for the proctor, no paper/pen/water/food allowed during the exam
Easiest Trap to Fall Into

"Which service is simplest" and "which service is best" often have different answers! For a static site, "simplest" is GCS + Load Balancer, but the "best" answer is usually App Engine. Read carefully to see which one the question is actually asking.
